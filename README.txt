KEYDINTA XOGTA (Google Sheets - bilaash)
1. Samee Google Sheet cusub (sheets.google.com).
2. Fur: Extensions > Apps Script. Tirtir koodhka jira, ku dheji apps-script/Code.gs, kaydi.
3. Riix Deploy > New deployment > nooca "Web app".
   Execute as: Me | Who has access: Anyone. Riix Deploy oo ogolaw ogolaanshaha.
4. Koobiyee "Web app URL".
5. Fur js/main.js, beddel PASTE_YOUR_APPS_SCRIPT_URL_HERE oo ku dheji URL-ka.
6. Fur index.html, buuxi foomka - xogtu waxay ka muuqan doontaa Sheet-ka.

Haddii aad beddesho Code.gs, samee "New deployment" mar kale.
Bogga ku geli host kasta (Netlify, GitHub Pages, iwm).
